Try it in 60 seconds

  1. Share a note. On the Laptop, pick Save a note, choose Team and save. Watch it arrive on the Mobile a few seconds later, synced through the shared Qdrant Server.
  2. Keep one private. Save another as Only me. It never reaches the Mobile. Admin › Privacy proves it: every private note checked against everything that left the device.
  3. Cut the signal. Tap Online on the Mobile to go offline, then ask it a question. Search and the answer run on the device, with no cloud.
  4. Make a conflict. While the Mobile is offline, edit the same shared note on both devices, then reconnect. The newer edit wins and the other is kept, one tap to restore (Sync tab).
  5. Ask something general. “How long should I boil an egg?” matches no note, so it's answered from general knowledge and labelled as not from your notes.

What's inside

  • Hybrid search on the deviceQdrant Edge: meaning + keywords (BM25), fused with RRF, in ~1 ms
  • Offline-firstEvery note is saved and indexed locally before anything touches the network
  • Privacy enforced in codePrivate notes can't be serialised for the cloud; an egress ledger records every outbound request
  • Smart answer routingCloud AI when it's safe, on-device AI when a private note is involved or you're offline
  • Sync that healsQueues while offline, pushes on reconnect, tombstones for deletions, re-uploads if the server is reset
  • Explainable conflictsRevision numbers, last write wins, loser kept and restorable
  • Evolving memorySpots when a new note updates an old one; newer facts win in answers
  • Honest answersCites the notes it used; general-knowledge answers are clearly labelled

This is a shared public demo: everyone sees the same two devices. The AI runs on this server, so for true on-device privacy EdgeMind runs locally on your own machine.
